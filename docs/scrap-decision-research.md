# SCRAP 의사결정 연구 검토

현재 프로토타입의 출발점은 공정 KG의 상태 전이입니다. 의사결정 연구는 후보를 확보한 뒤 확인할 시험, 수탁 조건, 비용을 비교하는 단계에 각각 연결할 수 있습니다.

| 연구 | 우리 흐름에서 활용할 곳 | 필요한 데이터 |
| --- | --- | --- |
| 단계별 오염물질 검사 연구 | 혼합 플라스틱의 재질·충전재·오염 여부에 따라 추가 검사와 후보 경로를 다시 확인 | 시험법, 관측값, 시설별 수탁 규격. 국내 법정 요건은 별도 검증. [Polymers 원문](https://www.mdpi.com/2073-4360/18/10/1256) |
| 철 스크랩 성분 정보 가치 연구 | 성분을 더 알면 경로 선택이 얼마나 개선되는지 분석할 때 참고 | 로트별 성분 편차, 시설 판정 기준, 시험비와 오차, 반려·처리비·판매가. 논문의 EVPI는 완전한 정보의 가치이며 개별 검사 판단은 EVSI가 필요. [RCR 연구](https://www.sciencedirect.com/science/article/pii/S0921344924003525), [Mineral Economics 연구](https://link.springer.com/article/10.1007/s13563-022-00361-z) |
| 혼합 폐플라스틱 전처리 조합 연구 | 서로 다른 선별·세척 조합을 경로 후보로 비교하는 후속 설계 | 해당 로트 조성, 공정별 회수율·불순물 제거율·비용. 원문은 열분해 투입원료 사례. [Maastricht 연구 기록](https://cris.maastrichtuniversity.nl/en/publications/balancing-cost-and-quality-multi-level-modelling-of-sorting-and-p/) |
| 산업 폐기물 배분 최적화 | 물량을 여러 시설에 나눠 보내는 경우의 후속 설계 | 실제 수용량, 처리효율, 회수량과 손익. 논문의 검증 사례는 섬유 폐기물. [MethodsX 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC11260601/) |
| 품질 불확실성을 고려한 다기간 수거 | 여러 출발지와 업체를 묶어 반복적으로 수거할 때 | 로트별 품질 분포, 주기별 물량, 재고와 차량비. 독일 사례는 폐지 데이터. [OR Spectrum 원문](https://link.springer.com/article/10.1007/s00291-025-00808-z) |
| 공정 시뮬레이션과 LCA | 공정별 자원 사용·배출량을 연결해 경로를 비교할 때 | 물질수지, 에너지와 장비 성능, 같은 경계의 LCI. 원문은 생활폐기물 선별과 소각 사례. [Sustainable Production and Consumption 원문](https://www.sciencedirect.com/science/article/pii/S2352550926000825) |

프로토타입에서는 먼저 **어떤 공정 조건이 미확인인지와 그 조건을 어떻게 확인할지**를 업체 근거 옆에 보여줍니다. 시험·공정 데이터가 쌓이면 검사 전후에 바뀌는 후보를 기록하고, 비용과 품질 데이터가 있는 경우에 한해 경로 비교와 검사 가치 산정으로 확장할 수 있습니다.
