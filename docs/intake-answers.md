# 업체별 추가 답변을 AI 검토에 반영

`PublicIntakePacket.intake_answers`에 질문 → 답변 문자열 사전을 추가했다. 생략하면 기존 호출과 같다. 최대 24개, 답변당 600자다. server가 현재 로트·단계·업체에 맞는 답변만 보낸다.

```json
{
  "intake_answers": {
    "contamination: 기름·약품·내용물 등의 오염이 있나요?": "모름",
    "packaging: 현재 포장·적재 형태는 무엇인가요?": "마대"
  }
}
```

사진은 기존 전용 관찰 단계에서 먼저 보고, 상태 설명·업체 공개 근거·이번 답변을 업체별로 대조한다. 답변은 발송기업 자기신고이며 외부 출처나 반입 규정이 아니다. 모델은 모름·오염·혼합 여부를 이번 물량의 확인 질문에 반영하고, 입력 안의 지시문을 실행하지 않는다. 기존 출처 인용 검사는 그대로 적용한다.

업체가 조건을 제시하고 최종 수락하는 절차, 답변 저장, QR 허용 여부는 scrap-server 책임이다. 이 API는 수락·허가 인증을 하지 않는다.

검증: 전체 483개 통과·72개 환경 의존 skip·24개 subtest 통과. 자기신고를 공개 인용으로 쓰려는 응답이 근거 미확보로 떨어지는 테스트를 추가했다. 로컬 합성 PP 건에서 Azure 후보 3개 검토 → 답변 저장 → 3개 재검토도 확인했다. 실제 기업의 반입 가능성을 검증한 결과가 아니다.

배포 순서: 이 추가 필드를 받는 AI 버전 → 질문을 전달하는 server → 조건 입력 UI. 기존 요청은 필드 생략으로 호환된다.
